Módulos

Não é um bot. É uma plataforma modular.

Cada componente resolve um problema específico e deixa estado ou evidência para o próximo. Isso torna o sistema observável, substituível e menos dependente de um único fluxo monolítico.

DISCOVERY ativo

Collectors, Partner Scout e Social Scout

Fontes diferentes encontram sinais e anúncios candidatos sem transformar descoberta em confiança automática.

IDENTITY ativo

Canonical Catalog

Resolve quando anúncios diferentes representam o mesmo produto e mantém identidade estável para histórico.

INTELLIGENCE ativo

Price Intelligence

Conecta observações atuais ao histórico próprio e cria contexto para diferenciar queda real de marketing.

EVENTS ativo

Alert Engine

Transforma movimentos relevantes em eventos como queda detectada, preço-alvo atingido e novo menor preço.

PERSONALIZATION ativo

Watchlists e matching

Preferências pessoais são cruzadas com eventos reais para gerar alertas direcionados em vez de ruído geral.

DELIVERY V1

Outbox & Push Dispatcher

Persistência, tentativas, tickets, receipts e revogação de dispositivos formam a camada de entrega.

API ativo

Application API

Autenticação, produtos, preferências, watchlists, alertas e dispositivos ficam separados do plano administrativo.

CLIENT MVP

Public App Android

Login, catálogo, histórico, busca, watchlist, alertas, conta e registro de dispositivo em uma interface própria.

OPS ativo

Runtime supervisionado

Processos filhos, watchdog, recuperação, health checks e políticas fail-closed sustentam operação contínua.

Arquitetura

Uma decisão só avança quando a camada anterior deixa evidência.

A arquitetura favorece componentes pequenos, persistência explícita e contratos entre camadas. Isso facilita teste, auditoria, substituição de fontes e crescimento progressivo.

01 · Descoberta

sources → candidates

Coleta própria, parceiros e sinais sociais encontram candidatos sem conceder confiança automática.

02 · Validação

identity + price

Marketplace, identidade, preço e anomalias são avaliados antes de qualquer decisão editorial.

03 · Memória

catalog + history

Catálogo canônico e históricos próprios transformam observações isoladas em contexto comparável.

04 · Inteligência

score + events

Pontuação, Price Intelligence e Alert Engine classificam mudanças e criam eventos reutilizáveis.

05 · Distribuição

queue + personalization + delivery

Fila editorial, afiliados, watchlists, outbox e canais de entrega usam o mesmo núcleo de evidências.

06 · Clientes

api + mobile + web

A API e os clientes públicos consomem o domínio sem receber acesso aos controles internos do runtime.

Public App

A plataforma já tem uma interface para quem recebe o valor final.

O app Android leva o produto além do modelo “canal para todo mundo”: conta, catálogo, busca, histórico, watchlist, alertas, preferências e registro de dispositivo.

  • Autenticação e sessão persistente
  • Lista e detalhe de produtos com histórico
  • Watchlists com preço-alvo
  • Alertas personalizados por evento
  • Registro de dispositivo para infraestrutura de push
  • API de aplicação separada do plano administrativo
Colaboração

Um parceiro não precisa começar do zero.

A base técnica já existe. A oportunidade de colaboração está em acelerar produto, cobertura, distribuição, confiabilidade e transformação de dados em valor.

Onde colaboração técnica gera impacto

O projeto foi construído para aceitar componentes novos sem reescrever tudo. Algumas frentes têm alto retorno imediato.

  • engenharia de dados e enriquecimento de catálogo
  • mobile / frontend e experiência do Public App
  • infraestrutura, observabilidade e escala
  • ML/ranking para qualidade de descoberta
  • novas integrações e fontes de produto/preço

Onde uma parceria comercial acelera o projeto

A arquitetura já suporta a evolução para múltiplas fontes e superfícies. O gargalo deixa de ser “ter um bot” e passa a ser acesso, distribuição e contexto.

  • acesso a feeds, catálogos, campanhas ou APIs
  • parcerias de afiliados e distribuição
  • usuários piloto para validar personalização
  • dados e sinais adicionais de intenção de compra
  • visão de produto e canais para aquisição
